# bella-pizza-docker
Bella Pizza is a full-featured e-commerce web application for a fast-food restaurant, built with PHP and MySQL. It allows customers to browse a categorized menu, manage their shopping cart, and place secure orders online. Staff can access an admin dashboard to manage menu items, monitor orders in real time, manage employees, and view business analytics.

This project also integrates Amazon Payment Services (APS) for secure and reliable online payment processing.

Features
Responsive UI: Mobile-friendly, card-based layout with collapsible categories and smooth transitions

Customer Interface: Category-based menu, product images, cart management, and secure checkout

Admin Dashboard:

Role-based access (Admin and Support)

CRUD operations for menu items, categories, and employees

Drag-and-drop reordering and AJAX-powered search/filter

Real-time order updates, driver assignment logging

Revenue analytics with date filters and exportable charts/CSV

Security: CSRF protection, secure session management, server-side validation, and prepared statements

APS Integration: Integrated Amazon Payment Services to handle secure transactions during checkout

Tech Stack
PHP, MySQL, HTML5/CSS3, JavaScript (AJAX), Amazon Payment Services (APS)
